🕵️ Why OverScope？

AI coding agents are powerful, but they can be like overzealous new employees—they often do more than asked. Not maliciously, but just because they interpret instructions broadly, add extra "improvements," or lose track of original goals. This is called scope creep.

  • 🧩 Out-of-scope edits – You asked for a button color change, but the AI refactored the entire component.
  • 💩 Deleted tests – It removed a test suite it thought was unnecessary, breaking your validation.
  • 🧪 Hidden dependencies – It added new libraries without telling you, causing bloat and potential security risks.
  • ⚠️ False completion claims – It says “all done,” but the tests fail or the feature was never implemented.

overscope catches all of this instantly. It’s like a radar for your AI assistant’s activity.

🔍 How OverScope Works (But in Simple Terms)

Overscope works entirely on your computer. No data leaves your machine. No AI is used—it’s purely deterministic. That means if you run it a hundred times, you get a hundred identical results. You can trust it like an old-school calculator.

  1. Before you start your AI helper, you tell overscope what your "scope" is—i.e., what files you expect to change.
  2. You let Claude Code or Codex do its magic.
  3. Then you run overscope and it compares the AI'agent session logs with your git diff (the record of file changes).
  4. It reports mismatches: Files you didn’t plan to touch, tests that were removed, new dependencies added, any signs of "completion theater."

Think of it as: you’re the lead engineer, and overscope is your meticulous QA inspector who checks that the contractor (AI) didn’t pour concrete on the flower bed.

🤳 Frequently Asked“Agentic" Questions

Q: Is this another AI model?

No, completely not. Overscope uses static analysis and simple pattern matching. It’s like a spell checker for scope—no machine learning involved.

Q: Do I need to know Claude Code / Codex to use it?

You need to have the sessions logs produced by those tools (which are saved automatically), but you don’t need deep expertise in them. The tool understands the session formats for both.

Q: Will this slow down my commit process?

Overscope is fast—typically under a couple seconds. It only compares structured logs against a diff. No heavy processing.

Q: Can I use it with other AI code tools?

Currently it supports Claude Code and Codex sessions natively. But as it’s open-source, community adapters can be built for other agents. The current version focuses on the two most popular coding agents.
